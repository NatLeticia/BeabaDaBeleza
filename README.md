## Objetivo do Software
O sistema Beabá da Beleza é uma solução de software desktop que visa centralizar e facilitar o agendamento de serviços de beleza e estética. O objetivo principal é atuar como um canal entre profissionais autônomos da área da beleza (freelancers) e clientes, organizando demandas, agenda, logística dos atendimentos exibindo portfólios, garantindo uma experiência de atendimento prática e satisfatória através do atendimento externo ou em espaços próprios.
##  Funcionalidades do Sistema (Requisitos)
* **RF001** - Cadastro de serviços (Inclusão e controle de valores pela Empresa).
* **RF002** - Cadastro de Profissionais (Registro de especialidades e portfólio, sujeito a aprovação).
* **RF003** - Cadastro de Clientes (Registro de dados básicos para acesso aos serviços).
* **RF004** - Visualização de Tabela de Serviços disponíveis.
* **RF005** - Busca por Profissionais de acordo com a especialidade e agendamento de horário.
* **RF006** - Gerenciamento de Solicitações (Profissionais podem aceitar ou recusar pedidos de agendamento).
